# Gallery assets

This folder stores gallery item assets for the site.

Each gallery item should be placed in its own subfolder. The folder name should match the gallery item's reference name used by the application.

Each item folder must include:
- a file named `title.jpg` for the gallery thumbnail
- one or more additional image files named with numeric values such as `1.jpg`, `2.jpg`, `3.jpg`, and so on

The gallery UI uses the `title.jpg` file as the thumbnail image for each item.
